# Checklist de uso responsável de IA

- [ ] O uso foi autorizado pela instituição?
- [ ] Não há dados identificáveis de pacientes ou outros dados confidenciais?
- [ ] Fontes e normas foram conferidas no documento oficial?
- [ ] Data e versão estão corretas?
- [ ] Uma pessoa competente revisou a entrega?
- [ ] A saída distingue fatos, hipóteses e sugestões?
- [ ] A decisão permanece com os responsáveis?
