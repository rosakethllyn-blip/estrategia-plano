# Modo Estrateg[IA] — Material da Aula 01

## Por que Claude Code?

O Claude Code combina linguagem natural com ferramentas capazes de trabalhar em arquivos e projetos. Pode apoiar protótipos de agendas de equipe, painéis com dados fictícios, sites, checklists e organização de processos. Um protótipo **não é** sistema institucional pronto.

## Modelos em uma frase

- **Haiku:** consultas e tarefas rápidas.
- **Sonnet:** equilíbrio para a maior parte do trabalho.
- **Opus:** raciocínio para problemas mais complexos; pode consumir mais da cota.

Veja o que está disponível na sua conta usando `/model`.

## Instalação mais fácil

1. Acesse **https://claude.com/download**.
2. Baixe o **Claude Desktop** para seu sistema e instale.
3. Faça login em conta elegível.
4. Abra a aba **Code**; não é necessário instalar a CLI separadamente.
5. No Windows, tenha **Git for Windows** para sessões locais. Reinicie Claude depois de instalar o Git.
6. Crie uma pasta de exercícios sem documentos reais e selecione-a no Code.
7. Leia as permissões antes de autorizar qualquer ação.

**Alternativas**, não ensinadas nesta primeira aula: terminal/PowerShell e IDE.

## Primeiro comando para copiar

```text
Estou aprendendo a usar o Claude Code. Trabalhe apenas dentro desta pasta de treinamento, que contém somente dados fictícios.

Antes de criar qualquer arquivo, me diga em três tópicos o que pretende fazer e peça minha autorização.

Depois da minha aprovação, crie um arquivo chamado PRIMEIRO-PROJETO.md contendo:
1. O título "Meu primeiro projeto no Claude Code".
2. Três ideias de ferramentas simples que poderiam apoiar um gestor da saúde, usando apenas dados fictícios.
3. Um checklist com cinco cuidados antes de trabalhar com qualquer arquivo institucional.
4. Uma mensagem final: "Este é apenas um exercício, não é uma ferramenta institucional".

Não execute instalações adicionais, não acesse outras pastas e não modifique arquivos existentes.
```

**Atenção:** nunca peça uso de dados clínicos reais neste exercício. Se a ferramenta não agir como previsto, corrija o comando e revise as permissões.
